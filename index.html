Database (MySQL & SQL Language) 01. Introduction to Database & MySQL

01. ស្វែងយល់អំពី Database, RDBMS និង MySQL

1. Definition (និយមន័យ):

Database (មូលដ្ឋានទិន្នន័យ) គឺជាកន្លែងសម្រាប់ផ្ទុក និងរៀបចំទិន្នន័យឱ្យមានរបៀបរៀបរយនៅក្នុងប្រព័ន្ធកុំព្យូទ័រ ដើម្បីងាយស្រួលក្នុងការស្វែងរក កែប្រែ លុប និងគ្រប់គ្រងប្រកបដោយសុវត្ថិភាព។

2. ប្រភេទនៃ Database (ចែកចេញជា ២ ប្រភេទធំៗ):

  • Relational Database (RDBMS / SQL)៖ ផ្ទុកទិន្នន័យជាទម្រង់ តារាង (Tables) មាន Columns & Rows ដែលអាចភ្ជាប់ទំនាក់ទំនងគ្នាបាន (ឧ. MySQL, SQL Server, PostgreSQL)។
  • Non-Relational Database (NRDBMS / NoSQL)៖ ផ្ទុកទិន្នន័យជាទម្រង់ Document (JSON) ឬ Key-Value ដោយមិនប្រើតារាងទេ (ឧ. MongoDB, Firebase, Redis)។

3. ក្រុមនៃពាក្យបញ្ជា SQL (SQL Command Categories):

  • DDL ៖ បង្កើត ឬកែប្រែរចនាសម្ព័ន្ធតារាង (CREATE, ALTER, DROP)។
  • DML ៖ បញ្ចូល កែប្រែ និងលុបទិន្នន័យ (INSERT, UPDATE, DELETE)។
  • DQL ៖ ទាញយកទិន្នន័យ (SELECT) និង DCL/TCL សម្រាប់គ្រប់គ្រងសិទ្ធិ និង Transaction។

4. Syntax (ទម្រង់ទូទៅ):

CREATE DATABASE database_name;
USE database_name;
SHOW DATABASES;

5. Example (ឧទាហរណ៍កូដ):

-- បង្កើត Database ថ្មី និងជ្រើសរើសយកមកប្រើប្រាស់
CREATE DATABASE school_db;
USE school_db;

-- បង្ហាញបញ្ជី Database ទាំងអស់ក្នុង Server
SHOW DATABASES;
6. Summary (សង្ខេបមេរៀន)៖ MySQL ស្ថិតក្នុងក្រុម RDBMS (SQL) សម្រាប់ផ្ទុកទិន្នន័យជាតារាង ចំណែក SQL គឺជាភាសាស្តង់ដារសម្រាប់បញ្ជាឱ្យ MySQL ធ្វើការងារ។

Database (MySQL & SQL Language) 02. Data Types & Constraints

02. ប្រភេទទិន្នន័យ (Data Types) និង Constraints

1. MySQL Data Types (ប្រភេទទិន្នន័យសំខាន់ៗ):

Data Type ក្រុមទិន្នន័យ ការពន្យល់ និងការប្រើប្រាស់
INT / BIGINT លេខគត់ ផ្ទុកចំនួនគត់ ដូចជា ID, អាយុ, ចំនួនស្តុកទំនិញ។
DECIMAL(10,2) លេខទសភាគ ផ្ទុកលេខទសភាគជាក់លាក់ ស័ក្តិសមសម្រាប់តម្លៃលុយ (ឧ. 99.50)។
VARCHAR(n) អក្សរ / ឃ្លា ផ្ទុកអក្សរប្រវែងប្រែប្រួល (អតិបរមា n តួអក្សរ) ដូចជា ឈ្មោះ, Email។
TEXT / DATETIME អត្ថបទ / ថ្ងៃម៉ោង TEXT ផ្ទុកអត្ថបទវែង និង DATETIME ផ្ទុក YYYY-MM-DD HH:MM:SS។

2. Table Constraints (លក្ខខណ្ឌការពារទិន្នន័យ):

  • PRIMARY KEY ៖ កំណត់ Column ជាលេខសម្គាល់តែមួយគត់ (មិនស្ទួន និងមិនអាចទទេ)។
  • AUTO_INCREMENT ៖ បង្កើនលេខ ID ដោយស្វ័យប្រវត្តិរាល់ពេលបញ្ចូលទិន្នន័យថ្មី (1, 2, 3...)។
  • NOT NULL ៖ បង្ខំឱ្យត្រូវតែបញ្ចូលទិន្នន័យ មិនអនុញ្ញាតឱ្យទុកទទេឡើយ។
  • UNIQUE ៖ ការពារកុំឱ្យទិន្នន័យក្នុង Column នោះជាន់គ្នា (ឧ. Email ឬលេខទូរស័ព្ទ)។
  • DEFAULT ៖ កំណត់តម្លៃដើមដោយស្វ័យប្រវត្តិ ប្រសិនបើអ្នកប្រើប្រាស់មិនបានបញ្ចូល។

3. Syntax (ទម្រង់ទូទៅ):

CREATE TABLE table_name (
    column1 datatype constraints,
    column2 datatype constraints, ...
);

4. Example (ឧទាហរណ៍កូដ):

CREATE TABLE students (
    id INT PRIMARY KEY AUTO_INCREMENT,
    full_name VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    tuition_fee DECIMAL(8, 2) DEFAULT 0.00
);
5. Summary (សង្ខេបមេរៀន)៖ ការជ្រើសរើស Data Type និង Constraints ឱ្យបានត្រឹមត្រូវ ជួយសន្សំសំចៃ Memory និងការពារកុំឱ្យមានទិន្នន័យខុសឆ្គង ឬស្ទួន។

Database (MySQL & SQL Language) 03. Managing Databases & Tables (DDL)

03. ការបង្កើត និងគ្រប់គ្រង Database & Tables (DDL)

1. Definition (និយមន័យ) និងឃ្លាបញ្ជា DDL:

DDL (Data Definition Language) គឺជាក្រុមឃ្លាបញ្ជា SQL សម្រាប់បង្កើត កែប្រែ និងលុបរចនាសម្ព័ន្ធរបស់ Database និង Tables៖

  • CREATE ៖ បង្កើត Database ឬតារាងថ្មី។
  • IF NOT EXISTS ៖ ពិនិត្យមុននឹងបង្កើត ដើម្បីការពារកុំឱ្យមាន Error ប្រសិនបើ Database ឬតារាងនោះមានរួចហើយ។
  • ALTER TABLE ៖ កែប្រែរចនាសម្ព័ន្ធតារាង — បន្ថែម (ADD), កែប្រភេទ (MODIFY), ឬលុប (DROP) Column។
  • RENAME TABLE ៖ ប្តូរឈ្មោះតារាងដែលមានស្រាប់ទៅជាឈ្មោះថ្មី។
  • TRUNCATE ៖ សម្អាតទិន្នន័យទាំងអស់ក្នុងតារាង (រក្សាទុករចនាសម្ព័ន្ធតារាង និង Reset ID)។
  • DROP ៖ លុប Database ឬតារាងចោលទាំងស្រុង (បាត់ទាំងរចនាសម្ព័ន្ធ និងទិន្នន័យ)។

2. Syntax (ទម្រង់ទូទៅ):

CREATE DATABASE [IF NOT EXISTS] database_name;
CREATE TABLE [IF NOT EXISTS] table_name (col1 datatype, col2 datatype, ...);
ALTER TABLE table_name ADD | MODIFY | DROP COLUMN column_name [datatype];
RENAME TABLE old_table_name TO new_table_name;
TRUNCATE TABLE table_name;
DROP TABLE [IF EXISTS] table_name;

3. Example (ឧទាហរណ៍កូដ):

-- ១. បង្កើតតារាងថ្មី (CREATE)
CREATE TABLE IF NOT EXISTS products (id INT PRIMARY KEY, name VARCHAR(100));

-- ២. បន្ថែម, កែប្រភេទ និងលុប Column (ALTER TABLE)
ALTER TABLE products ADD COLUMN stock INT DEFAULT 0;
ALTER TABLE products MODIFY COLUMN name VARCHAR(200) NOT NULL;
ALTER TABLE products DROP COLUMN stock;

-- ៣. ប្តូរឈ្មោះតារាង, សម្អាតទិន្នន័យ និងលុបតារាង (RENAME, TRUNCATE, DROP)
RENAME TABLE products TO items;
TRUNCATE TABLE items;
DROP TABLE IF EXISTS items;
ចំណាំសំខាន់៖ ត្រូវប្រុងប្រយ័ត្នខ្ពស់ពេលប្រើ DROP និង TRUNCATE ព្រោះទិន្នន័យដែលបានលុបមិនអាច Undo (ROLLBACK) មកវិញបានទេ។
4. Summary (សង្ខេបមេរៀន)៖ ប្រើ CREATE ដើម្បីបង្កើត, ALTER កែប្រែជួរឈរ, RENAME ប្តូរឈ្មោះតារាង, TRUNCATE សម្អាតទិន្នន័យ និង DROP លុបតារាង។

Database (MySQL & SQL Language) 04. Insert, Update & Delete (DML)

04. ការបញ្ចូល កែប្រែ និងលុបទិន្នន័យ (DML)

1. Definition (និយមន័យ):

DML (Data Manipulation Language) គឺជាក្រុមឃ្លាបញ្ជា SQL សម្រាប់គ្រប់គ្រង និងកែសម្រួលទិន្នន័យ (Rows) នៅក្នុងតារាងនៃ Database។

2. មុខងារសំខាន់ៗ (DML Commands):

  • INSERT INTO ៖ ប្រើសម្រាប់បញ្ចូលជួរទិន្នន័យ (Rows) ថ្មីមួយ ឬច្រើនជួរចូលទៅក្នុងតារាង។
  • UPDATE ... SET ៖ ប្រើសម្រាប់កែប្រែតម្លៃទិន្នន័យដែលមានស្រាប់ ដោយផ្អែកតាមលក្ខខណ្ឌ WHERE។
  • DELETE FROM ៖ ប្រើសម្រាប់លុបជួរទិន្នន័យជាក់លាក់ចេញពីតារាង ដោយផ្អែកតាមលក្ខខណ្ឌ WHERE។

3. Syntax (ទម្រង់ទូទៅ):

INSERT INTO table_name (column1, column2, ...) VALUES (value1, value2, ...);
UPDATE table_name SET column1 = value1, column2 = value2, ... WHERE condition;
DELETE FROM table_name WHERE condition;

4. Example (ឧទាហរណ៍កូដ):

-- ១. បញ្ចូលទិន្នន័យថ្មីចូលក្នុងតារាង category
INSERT INTO category (name, description)
VALUES ('Laptop', 'កុំព្យូទ័រយួរដៃ'), ('Phone', 'ទូរស័ព្ទឆ្លាតវៃ');

-- ២. កែប្រែទិន្នន័យតាមលក្ខខណ្ឌ WHERE
UPDATE category
SET name = 'Gaming Laptop', description = 'កុំព្យូទ័រសម្រាប់ Gaming'
WHERE id = 1;

-- ៣. លុបទិន្នន័យដែលមាន id = 7 ឬលុបច្រើនជួរ
DELETE FROM category WHERE id = 7;
DELETE FROM brands WHERE id IN (6, 8, 9);
ការព្រមានសំខាន់៖ ហាមភ្លេចដាក់ WHERE ពេលសរសេរ UPDATE ឬ DELETE! ប្រសិនបើគ្មាន WHERE ទេ MySQL នឹងកែប្រែ ឬលុបទិន្នន័យ គ្រប់ជួរទាំងអស់ ក្នុងតារាងភ្លាមៗ។
5. Summary (សង្ខេបមេរៀន)៖ INSERT សម្រាប់បន្ថែម, UPDATE សម្រាប់កែប្រែ និង DELETE សម្រាប់លុបទិន្នន័យ ដោយត្រូវភ្ជាប់ WHERE ជាមួយ Primary Key (id) ជានិច្ច។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 6
Database (MySQL & SQL Language) 05. Querying & Filtering Data

05. ការទាញយក និងច្រោះទិន្នន័យ (SELECT & WHERE)

1. ប្រមាណវិធីច្រោះទិន្នន័យសំខាន់ៗ (Filtering Operators):

  • Comparison Operators (ប្រៀបធៀបតម្លៃ)៖
    • = ៖ ស្មើនឹង (Equal)។
    • != ឬ <> ៖ មិនស្មើនឹង (Not Equal)។
    • > ៖ ធំជាង (Greater Than)។
    • < ៖ តូចជាង (Less Than)។
    • >= ៖ ធំជាង ឬស្មើ (Greater Than or Equal)។
    • <= ៖ តូចជាង ឬស្មើ (Less Than or Equal)។
  • Logical Operators (តក្កវិទ្យា)៖
    • AND ៖ ពិត លុះត្រាតែលក្ខខណ្ឌទាំងអស់ពិតដូចគ្នា។
    • OR ៖ ពិត ប្រសិនបើមានលក្ខខណ្ឌយ៉ាងតិចមួយពិត។
    • NOT ៖ ត្រឡប់លក្ខខណ្ឌឱ្យផ្ទុយពីដើម។
  • BETWEEN a AND b ៖ ច្រោះតម្លៃដែលស្ថិតនៅចន្លោះពី a ដល់ b (រាប់បញ្ចូលទាំងពីរ)។
  • IN (v1, v2, ...) ៖ ច្រោះតម្លៃដែលត្រូវនឹងធាតុណាមួយក្នុងបញ្ជី (ខ្លីជាងប្រើ OR ច្រើនដង)។
  • LIKE ៖ ស្វែងរកតាមលំនាំអក្សរ (Pattern) ដោយប្រើ % (តួអក្សរច្រើន) និង _ (១ តួអក្សរ)។
  • IS NULL / IS NOT NULL ៖ ពិនិត្យមើលតម្លៃទទេ ឬមិនទទេ (មិនអាចប្រើ = NULL បានទេ)។

2. Syntax (ទម្រង់ទូទៅ):

SELECT * FROM table_name;                         -- ទាញយកគ្រប់ Column និងគ្រប់ជួរ
SELECT * FROM table_name WHERE condition;         -- ទាញយកគ្រប់ Column តាមលក្ខខណ្ឌ
SELECT column1, column2, ... FROM table_name WHERE condition;

3. Example (ឧទាហរណ៍កូដ):

-- ១. ទាញយកតែ Columns ចាំបាច់តាមលក្ខខណ្ឌ
SELECT full_name, tuition_fee FROM students WHERE tuition_fee >= 120;

-- ២. ច្រោះដោយប្រើ BETWEEN និង IN
SELECT * FROM products WHERE price BETWEEN 10 AND 50;
SELECT * FROM users WHERE city IN ('Phnom Penh', 'Siem Reap');

-- ៣. ស្វែងរកតាមលំនាំអក្សរ LIKE និងតម្លៃទទេ IS NOT NULL
SELECT * FROM students WHERE full_name LIKE 'សុខ%' AND phone IS NOT NULL;
4. Summary (សង្ខេបមេរៀន)៖ នៅក្នុងប្រព័ន្ធពិត គួរសរសេរឈ្មោះ Column ជាក់លាក់ជំនួស SELECT * ដើម្បីឱ្យ Query ដំណើរការលឿន និងសន្សំសំចៃ Bandwidth។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 7
Database (MySQL & SQL Language) 06. Sorting, Pagination & Aliases

06. ការតម្រៀប និងកំណត់ចំនួនទិន្នន័យ (ORDER BY & LIMIT)

1. ឃ្លាបញ្ជាសម្រាប់រៀបចំលទ្ធផលទិន្នន័យ៖

  • ORDER BY ៖ តម្រៀបទិន្នន័យតាមលំដាប់កើន ASC (តូចទៅធំ) ឬលំដាប់ចុះ DESC (ធំទៅតូច)។
  • LIMIT n ៖ កំណត់ចំនួនជួរដេកអតិបរមាដែលត្រូវបង្ហាញ (ឧ. ទាញយកទំនិញលក់ដាច់ Top 5)។
  • OFFSET m ៖ រំលងទិន្នន័យចំនួន m ជួរដំបូង (ប្រើគូជាមួយ LIMIT ដើម្បីធ្វើ Pagination)។
  • DISTINCT ៖ ច្រោះយកតែតម្លៃដែលមិនជាន់គ្នា (លុបទិន្នន័យស្ទួនចេញពីលទ្ធផល)។
  • AS (Alias)៖ ដាក់ឈ្មោះក្លែងក្លាយបណ្តោះអាសន្នឱ្យ Column ឬ Table ដើម្បីឱ្យលទ្ធផលងាយអាន។

2. Syntax (ទម្រង់ទូទៅ):

SELECT DISTINCT column1 AS alias_name
FROM table_name
WHERE condition
ORDER BY column1 ASC | DESC
LIMIT count OFFSET skip_rows;

3. Example (ឧទាហរណ៍កូដ):

-- ១. ទាញយកខេត្ត/ក្រុងដោយមិនជាន់ឈ្មោះ និងទាញយកផលិតផលថ្លៃបំផុត Top 5
SELECT DISTINCT city FROM users;

SELECT name AS product_name, price AS unit_price
FROM products ORDER BY price DESC LIMIT 5;

-- ២. ការធ្វើ Pagination (ទំព័រទី ២ ដោយ ១ ទំព័របង្ហាញ ១០ ជួរ)
SELECT id, full_name, email FROM students
ORDER BY id ASC LIMIT 10 OFFSET 10;
រូបមន្ត Pagination ក្នុង Web Development៖ OFFSET = (page_number - 1) * page_size។ ឧទាហរណ៍៖ ទំព័រទី 3 យក 10 ជួរ នោះ OFFSET = (3 - 1) * 10 = 20។
4. Summary (សង្ខេបមេរៀន)៖ លំដាប់សរសេរ Query ត្រឹមត្រូវគឺ SELECT ... FROM ... WHERE ... ORDER BY ... LIMIT ... OFFSET ...។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 8
Database (MySQL & SQL Language) 07. Aggregate Functions & Grouping

07. អនុគមន៍គណនា និងការផ្តុំទិន្នន័យ (GROUP BY & HAVING)

1. Aggregate Functions និងភាពខុសគ្នារវាង WHERE vs HAVING:

  • Aggregate Functions (អនុគមន៍គណនាស្ថិតិទាំង ៥)៖
    • COUNT() ៖ រាប់ចំនួនជួរដេកសរុប។
    • SUM() ៖ បូកសរុបតម្លៃលេខទាំងអស់ក្នុង Column។
    • AVG() ៖ គណនាតម្លៃមធ្យមភាគ (Average)។
    • MIN() ៖ ស្វែងរកតម្លៃតូចបំផុត (Minimum)។
    • MAX() ៖ ស្វែងរកតម្លៃធំបំផុត (Maximum)។
  • GROUP BY ៖ ប្រមូលផ្តុំទិន្នន័យដែលមានតម្លៃដូចគ្នាជាក្រុម ដើម្បីគណនាស្ថិតិ។
  • WHERE ៖ ច្រោះជួរដេកនីមួយៗ មុនពេល ធ្វើ GROUP BY (មិនអាចប្រើជាមួយ SUM/COUNT បានទេ)។
  • HAVING ៖ ច្រោះក្រុមទិន្នន័យ បន្ទាប់ពី ធ្វើ GROUP BY រួច (ប្រើជាមួយ SUM/COUNT/AVG)។

2. Syntax (ទម្រង់ទូទៅ):

SELECT column1, AGG_FUNC(column2)
FROM table_name
WHERE row_condition
GROUP BY column1
HAVING group_condition
ORDER BY column1;

3. Example (ឧទាហរណ៍កូដ):

-- ១. គណនាស្ថិតិទូទៅនៃការបញ្ជាទិញ
SELECT COUNT(*) AS total_orders, SUM(amount) AS revenue, AVG(amount) AS avg_val
FROM orders;

-- ២. បូកសរុបចំណូលតាមប្រភេទទំនិញ យកតែប្រភេទលក់បានលើស $500
SELECT category, COUNT(*) AS items, SUM(price) AS total_sales
FROM products
WHERE status = 'ACTIVE'
GROUP BY category
HAVING SUM(price) > 500
ORDER BY total_sales DESC;
4. Summary (សង្ខេបមេរៀន)៖ ប្រើ GROUP BY ដើម្បីធ្វើរបាយការណ៍សង្ខេប ហើយចងចាំថា WHERE មិនអាចប្រើជាមួយ SUM/COUNT បានទេ ត្រូវប្រើ HAVING ជំនួស។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 9
Database (MySQL & SQL Language) 08. Keys & Table Relationships

08. ទំនាក់ទំនងរវាងតារាង (Keys & Relationships)

1. Definition (និយមន័យ):

  • Keys (កូនសោទិន្នន័យ)៖ ជា Column ពិសេសប្រើសម្រាប់សម្គាល់ជួរដេកនីមួយៗឱ្យមានតែមួយគត់ (Primary Key) និងសម្រាប់ភ្ជាប់ទំនាក់ទំនងពីតារាងកូនទៅតារាងមេ (Foreign Key)។
  • Relationships (ទំនាក់ទំនងរវាងតារាង)៖ ជាការតភ្ជាប់ទិន្នន័យរវាងតារាង ២ ឬច្រើនចូលគ្នា ដើម្បីកាត់បន្ថយការផ្ទុកទិន្នន័យស្ទួន និងការពារភាពត្រឹមត្រូវនៃទិន្នន័យ។

2. ប្រភេទទំនាក់ទំនងទាំង ៣ ក្នុងការរចនា Database (ERD):

ប្រភេទទំនាក់ទំនង ការពន្យល់ និងឧទាហរណ៍ជាក់ស្តែង
One-to-One (1:1) ១ ជួរតារាង A ភ្ជាប់ជាមួយ ១ ជួរតារាង B (ឧ. ១ User មាន ១ Profile)។
One-to-Many (1:N) ១ ជួរតារាង A ភ្ជាប់ច្រើនជួរតារាង B (ឧ. ១ Customer មានច្រើន Orders) — ប្រើញឹកញាប់បំផុត!
Many-to-Many (M:N) ប្រើតារាងកណ្តាល (Junction Table) ដើម្បីភ្ជាប់ (ឧ. Students & Courses តាម enrollments)។

3. Syntax (ទម្រង់ទូទៅនៃ Foreign Key):

CREATE TABLE child_table (
    id INT PRIMARY KEY AUTO_INCREMENT,
    parent_id INT,
    FOREIGN KEY (parent_id) REFERENCES parent_table(id) ON DELETE CASCADE
);

4. Example (ឧទាហរណ៍កូដ):

CREATE TABLE customers (
    id INT PRIMARY KEY AUTO_INCREMENT,
    full_name VARCHAR(100) NOT NULL
);

CREATE TABLE orders (
    id INT PRIMARY KEY AUTO_INCREMENT,
    customer_id INT NOT NULL,
    total_amount DECIMAL(10, 2) NOT NULL,
    CONSTRAINT fk_orders_customer
        FOREIGN KEY (customer_id) REFERENCES customers(id)
        ON DELETE CASCADE ON UPDATE CASCADE
);
5. Summary (សង្ខេបមេរៀន)៖ Primary Key (PK) សម្គាល់ជួរដេកក្នុងតារាងមេ ចំណែក Foreign Key (FK) ភ្ជាប់តារាងកូនទៅតារាងមេ ដើម្បីបង្កើតជា Relationships ដ៏រឹងមាំ។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 10
Database (MySQL & SQL Language) 09. Joining Multiple Tables

09. ការភ្ជាប់តារាងចូលគ្នា (SQL JOINS)

1. Definition (និយមន័យ):

SQL JOIN គឺជាឃ្លាបញ្ជាប្រើសម្រាប់ទាញយក និងបញ្ចូលទិន្នន័យពីតារាង ២ ឬច្រើនចូលគ្នាតែមួយលទ្ធផល ដោយផ្អែកលើជួរឈរដែលមានទំនាក់ទំនងគ្នា (Primary Key និង Foreign Key)។

2. ប្រភេទ JOIN សំខាន់ៗទាំង ៤៖

INNER JOIN

ទាញយកតែជួរដេកណាដែលមានទិន្នន័យ ផ្គូផ្គងត្រូវគ្នាទាំងសងខាង។

LEFT JOIN

ទាញយក ទាំងអស់ពីតារាងឆ្វេង និងទិន្នន័យត្រូវគ្នាពីតារាងស្តាំ (បើគ្មានចេញ NULL)។

RIGHT JOIN

ទាញយក ទាំងអស់ពីតារាងស្តាំ និងទិន្នន័យត្រូវគ្នាពីតារាងឆ្វេង។

CROSS JOIN

គុណផ្គូផ្គងគ្រប់ជួរនៃតារាងទី ១ ជាមួយគ្រប់ជួរនៃតារាងទី ២។

3. Syntax (ទម្រង់ទូទៅ):

SELECT a.column1, b.column2
FROM table_a a
INNER | LEFT | RIGHT JOIN table_b b ON a.id = b.table_a_id;

4. Example (ឧទាហរណ៍កូដ):

-- ១. INNER JOIN: ទាញយកតែអតិថិជនដែលធ្លាប់បានបញ្ជាទិញ
SELECT c.full_name, o.id AS order_id, o.total_amount
FROM customers c
INNER JOIN orders o ON c.id = o.customer_id;

-- ២. LEFT JOIN: ទាញយកអតិថិជនទាំងអស់ (រួមទាំងអ្នកមិនទាន់ធ្លាប់ទិញ)
SELECT c.full_name, COUNT(o.id) AS total_orders
FROM customers c
LEFT JOIN orders o ON c.id = o.customer_id
GROUP BY c.id, c.full_name;
5. Summary (សង្ខេបមេរៀន)៖ ក្នុងការងារជាក់ស្តែង INNER JOIN និង LEFT JOIN ត្រូវបានប្រើប្រាស់ប្រមាណ ៩៥% នៃការសរសេរ Query ភ្ជាប់តារាងទាំងអស់។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 11
Database (MySQL & SQL Language) 10. Subqueries & CTE (Advance)

10. Subqueries និង Common Table Expressions (CTE)

1. Definition (និយមន័យ):

  • Subquery (Query ក្នុង Query)៖ គឺជាឃ្លាបញ្ជា SELECT នៅក្នុងវង់ក្រចក ( ... ) នៃ Query ធំមួយទៀត ដើម្បីផ្តល់លទ្ធផលយកទៅប្រៀបធៀប។
  • CTE (WITH)៖ គឺជាការបង្កើតតារាងបណ្តោះអាសន្នមានឈ្មោះច្បាស់លាស់ (MySQL 8.0+) ធ្វើឱ្យ Query ដែលស្មុគស្មាញ ក្លាយមកជាងាយអាន និងងាយថែទាំជាង Subquery។

2. Syntax (ទម្រង់ទូទៅ):

-- Subquery:  SELECT col FROM table1 WHERE col > (SELECT AVG(col) FROM table1);
-- CTE:       WITH cte_name AS (SELECT ...) SELECT * FROM cte_name;

3. Example (ឧទាហរណ៍កូដ):

-- ១. Subquery: រកផលិតផលដែលមានតម្លៃខ្ពស់ជាងតម្លៃមធ្យម
SELECT name, price FROM products
WHERE price > (SELECT AVG(price) FROM products);

-- ២. CTE (WITH): គណនាចំណូលតាមអតិថិជន រួចច្រោះយកតែអតិថិជន VIP (>= $500)
WITH customer_spending AS (
    SELECT customer_id, SUM(total_amount) AS total_spent
    FROM orders GROUP BY customer_id
)
SELECT c.full_name, cs.total_spent
FROM customers c
INNER JOIN customer_spending cs ON c.id = cs.customer_id
WHERE cs.total_spent >= 500;
4. Summary (សង្ខេបមេរៀន)៖ ប្រើ Subquery សម្រាប់លក្ខខណ្ឌខ្លីៗ ១ ជាន់ និងប្រើ CTE (WITH) សម្រាប់របាយការណ៍វិភាគទិន្នន័យកម្រិតខ្ពស់ដែលមានច្រើនដំណាក់កាល។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 12
Database (MySQL & SQL Language) 11. Views & Indexes (Performance)

11. ការបង្កើត Views និងការបង្កើនល្បឿនដោយ Indexes

1. Definition (និយមន័យ):

  • SQL View (តារាងនិម្មិត)៖ គឺជាការរក្សាទុក Query ស្មុគស្មាញទុកជាឈ្មោះតារាងនិម្មិត ដើម្បីងាយស្រួលហៅប្រើឡើងវិញ និងលាក់ជួរឈរសម្ងាត់ (ដូចជា Password)។
  • Database Index (B-Tree)៖ គឺជារចនាសម្ព័ន្ធដែលប្រៀបដូចជា «មាតិកាសៀវភៅ» ជួយឱ្យ MySQL ស្វែងរកទិន្នន័យរាប់លានជួរបានយ៉ាងលឿន ដោយមិនចាំបាច់អានគ្រប់ជួរ។

2. Syntax (ទម្រង់ទូទៅ):

CREATE OR REPLACE VIEW view_name AS SELECT ...;
CREATE INDEX index_name ON table_name (column1, column2);
EXPLAIN SELECT * FROM table_name WHERE condition;

3. Example (ឧទាហរណ៍កូដ):

-- ១. បង្កើត View និងហៅមកប្រើដូចតារាងធម្មតា
CREATE OR REPLACE VIEW v_order_summary AS
SELECT o.id, c.full_name, o.total_amount
FROM orders o INNER JOIN customers c ON o.customer_id = c.id;

SELECT * FROM v_order_summary WHERE total_amount > 100;

-- ២. បង្កើត Index លើ email និងពិនិត្យល្បឿនដោយ EXPLAIN
CREATE INDEX idx_students_email ON students(email);
EXPLAIN SELECT * FROM students WHERE email = 'dara@gmail.com';
4. Summary (សង្ខេបមេរៀន)៖ Views ជួយឱ្យកូដស្អាត និងមានសុវត្ថិភាព ចំណែក Indexes និង EXPLAIN គឺជាអាវុធសំខាន់បំផុតក្នុងការធ្វើឱ្យ Database ធំៗដំណើរការលឿន។
រៀបចំដោយ៖ លាត ប្រុស ទំព័រ 13
Database (MySQL & SQL Language) 12. Procedures, Triggers & ACID

12. Stored Procedures, Triggers និង Transactions (ACID)

1. មុខងារកម្រិតខ្ពស់ទាំង ៣ ក្នុង MySQL Server:

  • Stored Procedure៖ គឺជាបណ្តុំកូដ SQL ដែលរក្សាទុកក្នុង Server (ដូចជា Function) ហើយអាចហៅប្រើឡើងវិញដោយ CALL។
  • Trigger៖ គឺជាកូដ SQL ដែលដំណើរការដោយស្វ័យប្រវត្តិ BEFORE ឬ AFTER មានព្រឹត្តិការណ៍ INSERT, UPDATE, ឬ DELETE។
  • Transactions (ACID)៖ គឺជាការចងក្រង Query ច្រើនជាប្រតិបត្តិការតែមួយ — ជោគជ័យទាំងអស់ទើប COMMIT បើមាន Error ត្រូវ ROLLBACK។

2. Syntax (ទម្រង់ទូទៅ):

CREATE PROCEDURE proc_name(IN param datatype) BEGIN ... END;
START TRANSACTION;  [SQL Queries...]  COMMIT; (ឬ ROLLBACK;)

3. Example (ឧទាហរណ៍កូដ):

-- ១. Stored Procedure ទាញយកការបញ្ជាទិញតាម Customer ID
DELIMITER //
CREATE PROCEDURE GetCustomerOrders(IN p_cust_id INT)
BEGIN
    SELECT * FROM orders WHERE customer_id = p_cust_id;
END //
DELIMITER ;
CALL GetCustomerOrders(1);

-- ២. Transaction: ផ្ទេរប្រាក់ $100 ពីគណនី A ទៅគណនី B
START TRANSACTION;
    UPDATE accounts SET balance = balance - 100 WHERE id = 1;
    UPDATE accounts SET balance = balance + 100 WHERE id = 2;
COMMIT;
គោលការណ៍ ACID៖ Atomicity (ធ្វើទាំងអស់ ឬមិនធ្វើ), Consistency (ទិន្នន័យត្រឹមត្រូវ), Isolation (មិនរំខានគ្នា), Durability (មិនបាត់បង់ក្រោយ Commit)។
